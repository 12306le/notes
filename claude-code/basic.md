# Claude Code 基本操作

Claude Code 是 Anthropic 官方推出的命令行 AI 助手，相当于把 Claude 装进了你的终端，可以让它帮你读代码、写代码、运行命令、调试问题。

## 安装

### 方式一：npm 安装（推荐）

需要先有 Node.js 18 或更新的版本。

```bash
npm install -g @anthropic-ai/claude-code
```

### 方式二：原生安装包

去 [官方下载页](https://docs.claude.com/en/docs/claude-code/setup) 下载对应系统的安装包，双击安装即可，不需要 Node.js。

### 验证安装

```bash
claude --version
```

能输出版本号就说明装好了。

## 启动

在任意项目目录下打开终端，运行：

```bash
claude
```

第一次启动会提示登录。可以选：

- **Anthropic 官方账号**（需要付费订阅 Claude Pro 或 Max，或者用 API Key）
- **第三方 API**（详见 [第三方 API 配置](./third-party-api.md)）

登录之后就进入对话界面，直接打字提问就行。

## 退出

```
/exit
```

或者按 `Ctrl+D`。

## 常用快捷键

| 按键 | 作用 |
| --- | --- |
| `Esc` | 中断 Claude 当前的回答或工具调用 |
| `Esc` `Esc` | 回到上一条消息编辑 |
| `Ctrl+C` | 取消当前输入（再按一次退出） |
| `Ctrl+D` | 退出会话 |
| `Shift+Tab` | 切换权限模式（默认 / 自动接受 / 计划模式） |
| `↑` `↓` | 翻历史输入 |
| `\` + 回车 | 换行（不发送） |

## 常用斜杠命令

在输入框里输入 `/` 会弹出命令菜单。最常用的几个：

| 命令 | 作用 |
| --- | --- |
| `/help` | 查看帮助 |
| `/clear` | 清空当前对话历史（开新话题时用） |
| `/model` | 切换模型（Opus / Sonnet / Haiku） |
| `/config` | 打开配置面板（主题、字体大小等） |
| `/cost` | 查看本次会话的 token 消耗 |
| `/resume` | 恢复之前的会话 |
| `/exit` | 退出 |

## 引用文件和图片

### 引用文件

输入 `@` 会弹出文件选择器，选中文件后 Claude 就能读到它的内容。例如：

```
帮我看看 @src/main.js 里这个函数为什么报错
```

### 粘贴图片

直接 `Ctrl+V` 把截图粘贴进对话框，Claude 能看图。常用于：

- 把报错截图丢给它分析
- 给它看 UI 设计稿让它写前端代码
- 让它解读图表数据

## 权限模式

Claude 在执行修改文件、运行命令这类有副作用的操作前，默认会询问你。三种模式（用 `Shift+Tab` 切换）：

| 模式 | 行为 |
| --- | --- |
| **默认（Default）** | 危险操作前每次都问 |
| **自动接受（Auto-accept edits）** | 文件修改不再询问，但运行命令仍然询问 |
| **计划模式（Plan mode）** | 只读模式，Claude 只会规划、不会实际改任何东西 |

**建议**：刚开始用就用默认模式，看 Claude 想干什么再放权。等熟悉了它的风格再考虑自动接受。

## 第一次使用，可以这样试

1. 进入一个项目目录，运行 `claude`
2. 输入：`帮我看看这个项目是干什么的，主要文件有哪些`
3. 看 Claude 怎么用工具去探索你的代码
4. 然后试试让它做点小事，比如：`在 README.md 末尾加一句"作者很帅"`
5. 注意它会先告诉你要改什么，等你确认才动手

## 常见疑问

**Q：会不会偷偷把我代码上传到哪里？**
A：代码内容会作为对话上下文发给 Anthropic 的服务器（这是它工作的原理）。但 Anthropic 承诺不用你的数据训练模型。如果用第三方 API，数据就发给第三方了，注意选靠谱的。

**Q：Claude Code 和 Cursor、GitHub Copilot 有什么区别？**
A：Cursor 和 Copilot 是嵌在编辑器里的，主要做代码补全和聊天。Claude Code 是命令行工具，更擅长跑命令、做多步任务、跨文件改动。三者可以共存。

**Q：每次都要重新介绍项目吗？**
A：在项目根目录建一个 `CLAUDE.md` 文件，写上项目简介、技术栈、规范等。Claude 启动时会自动读它。
